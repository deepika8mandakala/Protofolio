03 // PROJECTS

Systems Built

NLI · RAG · REAL-TIME MONITORING
VeritasAI

Evidence-grounded claim verification platform for real-time social monitoring. Classifies claims as Supported, Contradicted, or Insufficient with DeBERTa-v3-base, BGE embeddings, and FAISS retrieval, then exposes the pipeline through FastAPI and Streamlit/Gradio interfaces.

Mastodon Claims→ BGE + FAISS→ DeBERTa NLI→ Evidence Verdict
DeBERTa-v3-baseBGE Embeddings FAISSFastAPI SQLAlchemyGradio
Live Demo ↗ GitHub
Problem
Fast-moving social feeds make it difficult to separate a claim from the evidence needed to verify it. Binary labels also hide uncertainty when retrieved context is incomplete.
Approach
Combines 449 evidence vectors with DeBERTa-v3-base NLI classification and a 0.60 confidence threshold. Mastodon REST/WebSocket ingestion, SQLAlchemy persistence, and 9 FastAPI endpoints support real-time workflows.
Research Angle
Treats claim verification as an evidence-grounded decision system: retrieval quality, entailment confidence, and an explicit Insufficient outcome remain visible to the user.
GEOSPATIAL · SAFETY · ML
SmartFoot

AI-powered pedestrian safety routing system that scores walking routes (0–100) across 8 safety factors using Random Forest trained on 25+ OSM features. Integrates 4 geospatial APIs for route planning, circular walks, and GPS navigation with 3 route options. Migrated to Leaflet for cost-free, scalable deployment.

OSM + GPS Data → 25+ Features → RandomForest → Safety Score 0–100
RandomForest OSM / Leaflet 4 Geospatial APIs Python Flask
Live Demo ↗ GitHub
Problem
Urban pedestrian safety is unmeasured and subjective. No tool provides ML-driven, real-time walkability scores at scale using open geospatial data.
Approach
Built a Random Forest model trained on 25+ OSM features, scoring routes across 8 safety dimensions. Integrated 4 geospatial APIs for live route planning with ±10% duration accuracy. Leaflet migration cut deployment cost to zero.
Research Angle
Demonstrates that structured tree models outperform deep learning on tabular spatial data. Geospatial ML applied to social infrastructure at city scale.
NLP · BEHAVIORAL AI · DEVOPS
BrainSM

NLP-based social media behavior analysis platform with full ETL pipeline: ingest → sentiment analysis (HuggingFace) → PostgreSQL storage → Kibana dashboards. Includes daily graph generation, behavioral alert system via SMTP email, and containerized deployment with Docker Compose.

Social Media Data → HuggingFace NLP → PostgreSQL + Kibana → Alerts
Python HuggingFace PostgreSQL Elasticsearch Kibana Docker Compose SMTP
Live Demo ↗ GitHub
Problem
Social media encodes behavioral and cognitive signals that traditional psychology tools cannot capture at scale or speed.
Approach
Full ETL pipeline: ingest → HuggingFace sentiment analysis → PostgreSQL + Elasticsearch storage → Kibana dashboards. Docker Compose containerization makes the stack fully reproducible. SMTP alerts fire on behavioral anomaly thresholds.
Research Angle
Bridges computational linguistics with cognitive behavioral modeling. MLOps-grade infrastructure (Docker, Kibana, Elasticsearch) applied to social-science research — a direction aligned with neurosymbolic AI.
